# Crypto TG Scanner — парсер Telegram-ботов криптообменников

Ищет и сканирует Telegram-ботов криптообменников, которые принимают покупку BTC
**ручным способом**: перевод по СБП / на карту по реквизитам + приложение PDF-чека.

## Как это работает

1. **Discovery** — собирает `t.me`-username ботов из статей, каталогов и поисковиков
   (coindaily, vc.ru, dtf, top-ex, coinspot и др.). Пополняет базу `data/bots.json`.
2. **Scan** — через Telethon логинится в Telegram, заходит в каждого бота и гоняет
   сценарий покупки:
   - `/start` → `/buy` (или кнопка «Купить»)
   - ввод суммы пополнения (по умолчанию 5000 ₽)
   - ввод BTC-адреса
   - нажатие кнопок «Далее / Оплатить / Подтвердить»
   - сбор всего текста и кнопок интерфейса
3. **Анализ** — по собранному тексту определяет:
   - `has_manual_payment` — есть ручной способ (СБП / карта / реквизиты / оператор)
   - `has_pdf_check` — просят приложить чек / PDF / скриншот
   - `payment_methods` — найденные способы оплаты
4. **Web UI** — дашборд на localhost:8000: запуск скана, живой лог, таблица
   результатов, добавление/удаление ботов.

## Установка и запуск

```bash
cd crypto_scanner
pip install -r requirements.txt

# настройка
cp .env.example .env
# впиши TG_API_ID и TG_API_HASH (https://my.telegram.org -> API development tools)
# при первом запуске Telethon спросит номер телефона и код — это вход в твой аккаунт

# запуск web UI
uvicorn app:app --host 127.0.0.1 --port 8000
```

Открой **http://127.0.0.1:8000** в браузере.

## Что нажимать в UI

1. **«🔍 Найти новых ботов»** — соберёт ботов из веба в базу (работает без API-ключей).
2. **«▶ Сканировать все»** — прогонит всех ботов из базы через сценарий покупки.
   Результаты сохраняются в `data/results.json` инкрементально.
3. Вкладка **«Результаты»** — боты с ручной оплатой сверху, зелёный бейдж ✅.
   Клик «▸» раскрывает полный диалог с ботом.

## Прокси

Если Telegram блокирует твой IP — укажи в `.env`:

```
TG_PROXY=socks5://user:pass@host:port
```

Поддержка socks5/http/https.

## Важно

- Скан использует **твой личный аккаунт Telegram** — не гоняй тысячи ботов за раз
  с одного аккаунта без пауз, иначе Telegram может временно ограничить аккаунт.
- Для массового скана лучше использовать несколько аккаунтов/прокси.
- Ключевые слова ручной оплаты настраиваются в `core/scanner.py`
  (списки `MANUAL_SIGNALS`, `AUTO_SIGNALS`).
